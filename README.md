# CommerceIQ Data Platform

A learning and portfolio project that builds a reliable data platform
for a fictional e-commerce marketplace.

## Business problem

Orders, payments, and delivery information are spread across separate
sources. Teams need consistent reports and a clear way to investigate
payment differences and delivery problems.

## Project goal

Collect source data, validate it, build a PostgreSQL analytics warehouse,
and provide documented tables for business reporting.

## Planned technologies

- Python and Pandas
- SQL and PostgreSQL
- Docker Compose
- dbt Core
- Apache Airflow
- Pytest
- GitHub Actions
- Power BI
- AWS S3, IAM, EC2, and CloudWatch
- Terraform

## Data

The initial source will be the public Olist e-commerce dataset.

Later phases will introduce clearly labelled simulated updates.
Dataset usage terms will be reviewed before ingestion.

## Current status

Phase 0: project foundation and business requirements.

## Development approach

Build in small phases. Explain each change, verify its behaviour,
and track completed work through Git branches and pull requests.
